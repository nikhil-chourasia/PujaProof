# PujaProof — Lander & Waitlist Portal
Part of the **PujaProof** platform by **Team Poppins** for **HackSpire '26**.

For complete project architecture, technical specifications, slide decks, and roadmap, please see the [Main Project README](../README.md).

## Quick Start
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) for the landing page or [http://localhost:3000/waitlist](http://localhost:3000/waitlist) for the waitlist portal.
